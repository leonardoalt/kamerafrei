Surveillance under Surveillance uses data from OpenStreetMap contributors that is not visualized on the regular OpenStreetMap site.

I would like to build a navigator that minimizes the exposure to known cameras.
Initially only for walking/biking, focused on Berlin.
Ideally in this end this would work from the OsmAnd or a fork phone app too (much later).

The questions for now are:
- How do we build this? Do we need to download Berlin maps first?
- Can we build a simple website that shows the results or shortest paths with minimal cameras (like google maps style)? No need to navigate all the way, only show the paths, how many cameras, where they are, etc.
- Ideally this would be simply an overlay over OSM itself, feels possible somehow?

Make a plan for the MVP of the path planner that works on the browser.
